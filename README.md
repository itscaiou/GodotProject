# Mystic Adventure

Derrote inimigos, ganhe novos poderes e salve pequenos vilarejos dos mais perigosos inimigos.

## Sobre o jogo

Mystic Adventure é um projeto de um jogo 2D desenvolvido durante o terceiro semestre da minha faculdade de Ciência da Computação
como parte da disciplina de Experimentação de Protótipos utilizando GodotEngine.

O jogador deve avançar as fases derrotando os inimigos, enquanto lança poderes que podem ser desbloqueados conforme for avançando as fases.
Cada fase tem um inimigo diferente, com níveis de dificuldade que variam. No final, para vencer, o jogador deve derrotar a Vilâ Final e garantir
a paz de todo o reino.

Cada poder novo desbloqueado tem uma funcionalidade específica que pode ajudar o jogador durante os combates.

## Principais mecânicas

- Movimentação do personagem
- Diferentes fases
- Inimigos com perseguição
- Sistema de vidas
- Tepo de Recarga dos Poderes
- Telas de vitória e derrota

## Controles

| Ação | Tecla |
|---|---|
| Movimentar | Setas |
| Pular | Espaço ou Setas |
| Interagir | QWER |

## Tecnologias utilizadas

- Godot Engine [4.6]
- GDScript
- Canva
